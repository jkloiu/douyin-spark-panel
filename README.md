# 抖音火花面板 · 微信小程序

把现有网页面板（`/opt/DouYinSparkFlow`）搬到微信里，手机随时看火花、查记录、改任务、登录账号。

---

## 一、为什么需要中间那一层

微信小程序**不能**直接请求你的面板：

| 限制 | 现状 | 结果 |
|---|---|---|
| 只能请求 `https://` | 面板是 `http://` | ❌ |
| 域名必须已 ICP 备案 | 面板是裸 IP `121.36.38.180` | ❌ |
| 端口只能是 443 | 面板在 `8123` | ❌ |

所以中间加一层 **CloudBase 云函数**：小程序用 `wx.cloud.callFunction` 调它（云开发**不需要配置任何合法域名**），它再用普通 HTTP 去请求面板。

```
微信小程序
   │  wx.cloud.callFunction('panelApi')   ← 免域名配置
   ▼
云函数 panelApi（腾讯云 CloudBase，Node.js）
   │  http://121.36.38.180:8123/api/...
   ▼
现有 Flask 面板（抖音自动化都还在这里跑）
```

**抖音自动化一行都没搬** —— Playwright 那套（登录、抓会话、发消息）继续留在服务器，小程序只是它的一个手机遥控器兼仪表盘。

### 推送页上的两条通道怎么选、怎么删

小程序推送页有**两条互相独立**的通道，可以只留一条：

| | 微信服务通知 | 第三方通道（可选） |
|---|---|---|
| 是什么 | 小程序订阅消息，微信原生 | 网页面板那套 WxPusher / 企业微信机器人 / Server 酱 / Bark |
| 配置成本 | 授权一下就行，不用第三方账号 | 要去对方平台拿 Token + UID/webhook |
| 数据来源 | 云函数直接读面板日报，09:00 / 18:00 | 面板服务端的推送 cron（同一份 `push_config.json`） |
| 想要就… | 点「开启」（+1 额度） | 展开卡片选渠道、填密钥、打开「启用推送」再保存 |
| 不想要就… | 点「关闭服务通知」（**暂停**，额度留着） | 点「删除第三方通道」（**真删**：通道切回关闭 + 清空 Token 和地址） |

- **只想在微信里收 → 第三方通道保持「关闭」就行，什么都不用填**，两条通道互不影响。
- 「删除第三方通道」发的是 `PUT /api/push-config {channel:'', enabled:false, clear_token:true, clear_webhook:true}`。
  面板的 PUT 语义是「**留空 = 不修改**」，所以想真删必须显式带 `clear_*` 标记；
  反过来，普通「保存」不带 `clear_*` 就不会误清密钥（这条已写成联调用例）。
- 「只清除 Token」是更轻的一档：通道设置留着，只把密钥抹掉。

## 四、鉴权是怎么设计的

小程序端**不长期保存面板密码**：

```
① 登录页输入面板用户名 + 密码
② 云函数代调 /api/login，拿到 X-Panel-Token
③ 把 openid → {username, panelToken, expire} 写进 panel_sessions 集合
④ 之后小程序只发业务请求，云函数按 openid 取 token 转发
⑤ token 失效 → 云函数统一返回 NEED_LOGIN → 前端自动回登录页
```

- 面板 token 本身 24 小时过期，云函数按 20 小时预留
- **每个微信用户对应自己那条会话**，互不串号（已实测：openid B 拿不到 A 的会话）
- 面板侧的「多用户隔离」继续生效 —— 非管理员只能看到自己名下的抖音账号数据

## 五、通知红点是怎么算的

面板的 `/api/notifications` 是一条**只增不减的流水**（只有「清空」，没有「单条已读」），
所以红点不能直接拿列表长度算 —— 那样子点进去也永远消不掉。

小程序这边按**面板登录用户名**在本地存一条「已读水位线」：

```
红点 = 晚于水位线 且 类型不是 ok 的通知条数
```

- 水位线取**已加载列表里的最大 `t`**，而不是本机 `Date.now()` —— 手机时钟和服务器
  有偏差时，用本机时间会把刚到的新通知误判成已读。
- **所有入口必须走同一个口径**：`utils/notif.js` 的 `counts()`。概览页顶部的「通知」快捷入口
  曾经直接拿「非 ok 条数」当红点（漏了水位线），于是点进通知中心也消不掉 —— 已修，
  并在 `check_mp.py` 里加了静态检查（页面里出现 `type !== 'ok'` 直接报错）防回归。
- 写入时机：**进入通知中心、列表加载成功后就写水位线**（`load()` 里），
  不再只靠 `onHide` / `onUnload` —— 返回上一页时 `onUnload(本页)` 与 `onShow(上一页)`
  的先后顺序不保证，会让上一页的红点多残留一次。页面里的「新」标记在写入前就算好了，
  所以标「已读」不影响本次浏览还能看到哪些是新的。
- 「我的」页签同时挂角标（tabBar index 4），随红点一起清除。
- 每页面顶部有「全部已读」可手动清。面板侧的「清空」会真正删掉服务器记录。

## 六、界面与动效规范

界面**没有用任何 UI 组件库**，全部手写。好处是包体小、和面板风格一致；代价是
样式不统一会很快失控，所以定了几条硬规矩，并写进了静态自检。

| 组 | 变量 | 说明 |
|---|---|---|
| 颜色 | `--bg` `--card` `--card-2` `--txt/-2/-3` `--line/-2` `--primary/-2` `--grad-primary` `--ok` `--warn` `--danger`（各带 `-soft`） | 主色抖音红 `#FF2C55` |

| 类 | 作用 |
|---|---|
| `.stagger` | 加在最外层容器上，**直接子元素**按 40ms 递增依次淡入上移，最多 6 个 |
| `.anim` / `.anim--fade` / `--pop` / `--up` / `--down` | 单个元素的入场，`--d1…--d6` 手动错位 |
| `.tap` / `.tap-row` / `.tap-s` | 按压反馈三档：缩放 0.972 / 列表行底色压暗 / 小控件缩放 0.93 |
| `.card--tap` | 整卡当入口时用，按下缩放 + 抬高阴影 |
| `.live-dot` | 未读红点的呼吸光环（`::after` 扩散） |
| `.mask` | 弹层蒙层淡入；底部弹窗加 `.anim--up`、居中弹窗加 `.anim--pop` |
| `.fold` / `.fold__inner` | 折叠容器，见 6.3 |

**三条铁律**（都有自检断言）：

1. **入场动画的 `animation-fill-mode` 必须用 `backwards`，不能用 `both`。**
   `both` 会把末帧的 `transform: none` 永久钉住，把 `:active` 的缩放整个压掉 ——
   表现是「按压反馈莫名其妙不灵」，极难排查。`backwards` 只在延迟期间保留首帧防闪，
   动画一结束就把样式交还给正常规则。
2. **错位入场最多 6 个元素。** 联系人/通知这类列表动辄上百条，逐个入场会同时开上百个
   合成层，低端机明显掉帧；第 7 个起 `animation: none`（它们本来就在首屏之外）。
3. **⚠️ 选择器里不能用 `*`。** WXSS **不支持 `*` 通配符、`[attr]` 属性选择器，也不支持裸伪类**，
   写了整份 wxss 直接编译失败，开发者工具只给一句「编译 .wxss 文件错误」——
   而所有正则型自检仍然是绿的（它只在 wcsc 编译期才暴露）。
   所以 `.stagger` 的选择器只能**逐个列元素名**：

   ```css
   /* ✗ 全部报 error at token */  .stagger > *:not(.mask) / > [class]:not(.mask) / > :not(.mask)
   /* ✓ 全工程直接子元素只有 view 与 button（「我的」页「退出登录」） */
   .stagger > view:not(.mask),
   .stagger > button { animation: fadeUp var(--t-slow) var(--ease-out) backwards; }
   ```

   `.mask`（弹层蒙层，`position: fixed`）必须排除，否则会被祖先 `transform` 带偏；
   它都是 `view`，所以 `:not(.mask)` 挂在 `view` 上就够。
   **新增页面若在 `.stagger` 根下用了别的标签（`image` / `scroll-view`…），要同步加进这个列表**，
   否则那部分会静默不参与入场（`check_mp.py` 有一条自检专门比对「真实子元素 vs 选择器列表」）。

另外写了 `@media (prefers-reduced-motion: reduce)` 兜底，系统开了「减弱动态效果」就不播动画。

### 6.3 折叠过渡（推送页第三方通道）

原来是 `wx:if` 硬切换 —— 节点被销毁，所以**根本没有过渡**。现在改成常驻节点 + CSS 过渡：

```html
<view class="fold {{thirdOpen ? 'fold--open' : ''}}" style="max-height: {{foldH}}px">
  <view class="fold__inner">…</view>
</view>
```

`max-height` 由 JS 量出**内容真实高度**后写进行内样式（展开前先量，因为
`overflow: hidden` 只裁剪视觉、不影响子元素布局），这样过渡时长和内容高度是匹配的，
不会出现 `max-height` 从 0 transition 到一个大值导致的「先快后停」。

> ⚠️ 两个必须一起改的地方：收起时和删除配置时都要把 `foldH` **归零** ——
> 行内 `max-height` 会盖过 CSS 里的 `0`，不归零会出现「看不见但占位」的空白。
> 自检里加了断言：WXML 用了 `.fold` 而页面 JS 没有 `foldH` 就直接报错。

## 七、安全注意

云函数出口不受限，所以网关自己把了两道关：

1. **路径白名单**：只允许 `/api/`、`/data/avatars/`、`/shots/`、`/manifest.json` 前缀，
   且拒绝 `http://` 开头的绝对地址（防 SSRF 拿云函数当跳板）
2. **不落密码**：云数据库里只有 token，没有密码

> 现状提醒：面板 `8123` 端口目前是**公网可直接访问**的（这也是它现在能用手机 PWA 的原因）。
> 小程序上线并不改变这一点。如果想更安全，可以：
> - 用 nginx 对 `/api/login` 做失败次数限流
> - 或只允许腾讯云云函数出口 IP 段访问 8123（需要固定出口 IP，付费版才支持）
